\section{Introduction}

A Curriculum Vitae (CV) is a key document that represents your academic background, skills, and experiences. For students, it is often the first step toward securing internships, part-time jobs, or admission into competitive programs.

A well-structured CV helps recruiters quickly understand your profile and evaluate your potential. This guide provides practical advice and a complete template to help you build a professional and effective CV.

% ================== GENERAL GUIDELINES ==================
\section{General Guidelines}

\begin{itemize}
    \item Keep your CV concise (1 page for students, maximum 2 pages).
    \item Use a clean and professional font (e.g., Latin Modern, Arial, Helvetica).
    \item Maintain consistent formatting (spacing, alignment, bullet points).
    \item Use clear section titles.
    \item Avoid unnecessary graphics or excessive colors.
    \item Save your CV as a PDF.
\end{itemize}

% ================== CV STRUCTURE ==================
\section{CV Sections Explanation}

\subsection{Personal Information}
\begin{itemize}
    \item Full Name
    \item Phone Number
    \item Professional Email Address
    \item LinkedIn or Portfolio (optional but recommended)
\end{itemize}

\subsection{Education}
\begin{itemize}
    \item Degree and field of study
    \item Institution name
    \item Dates
    \item Relevant coursework (optional)
\end{itemize}

\subsection{Projects}
\begin{itemize}
    \item Academic or personal projects
    \item Technologies used
    \item Key achievements or outcomes
\end{itemize}

\subsection{Skills}
\begin{itemize}
    \item Technical skills (programming, tools, software)
    \item Soft skills (communication, teamwork, problem-solving)
\end{itemize}

\subsection{Experience}
\begin{itemize}
    \item Internships
    \item Part-time jobs
    \item Volunteer work
\end{itemize}

\subsection{Certifications / Training}
\begin{itemize}
    \item Online courses
    \item Professional certifications
\end{itemize}

\subsection{Languages}
\begin{itemize}
    \item Languages spoken with proficiency level
\end{itemize}

\subsection{Interests (Optional)}
\begin{itemize}
    \item Hobbies or interests that reflect your personality or skills
\end{itemize}

% ================== OPTIMIZATION ==================
\section{Tips for Optimization}

\begin{itemize}
    \item Use keywords relevant to the job description.
    \item Make your CV ATS-friendly (simple format, no tables/images).
    \item Customize your CV for each application.
    \item Highlight measurable achievements (e.g., improved performance by 20\%).
    \item Use action verbs (Developed, Designed, Implemented).
\end{itemize}

% ================== MISTAKES ==================
\section{Common Mistakes to Avoid}

\begin{itemize}
    \item Spelling and grammar errors
    \item Too much text or irrelevant information
    \item Unprofessional email address
    \item Lack of structure or consistency
    \item Copying generic templates without personalization
\end{itemize}
